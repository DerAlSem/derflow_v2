# sales-copy — конвейер продающего текста

Три чужих скилла, каждый силён в своём и вреден за своей границей. Этот файл —
только порядок, границы ступеней и то, чего ни один из них не знает: русское
право и откуда берутся факты.

## 0. Вход: файл контекста — или стоп

Сильный текст держится на фактах, стилевые ступени их не создают (humanizer-ru
прямо запрещает дописывать). Поэтому до первой строки текста нужен **файл
контекста аудитории** в репозитории сайта: `docs/marketing/<аудитория>.md`.
Одна аудитория — один файл: у зрителя шоу и у организатора корпоратива разные
страхи, и смешанный файл даёт текст ни для кого.

Файла нет или в нём нет нужного раздела → **интервью с владельцем**:
строго по одному вопросу за сообщение; где ответ укладывается в варианты —
предложи 2–4 варианта. Разделы файла — те, что `copywriting` спрашивает в
«Before Writing»: цель страницы и одно главное действие, аудитория и её слова,
возражения, чем отличаемся, доказательства, откуда трафик.

**Каждая цифра и каждое утверждение о результате в файле несёт источник**:
«владелец, интервью ДД.ММ.ГГГГ», «боевая база, запрос в `<файл>`, ДД.ММ.ГГГГ»,
«отзыв ВК, ссылка». Без источника — в раздел «гипотезы», в текст не идёт.

## 1. Ступень copywriting — пишет

Грузи скилл `copywriting`, контекст — файл выше (не `.agents/product-marketing.md`).
Поверх его правил — русская рамка:

- **ФЗ «О рекламе», ст. 5.** «Лучший», «№ 1», «самый», «единственный»,
  «лидер» — только с подтверждением, которое можно предъявить (исследование,
  рейтинг с датой и источником). Нет подтверждения — нет слова.
- Срочность только настоящая: «осталось N мест» — из живых данных продаж,
  «только сегодня» — только если цена правда меняется завтра. Выдуманный
  дедлайн — ложь покупателю и та же ст. 5.
- Отзывы — только реальные, дословно или с пометкой о сокращении, с
  указанием, откуда. Не сочинять, не «улучшать» чужие слова.
- Возрастная маркировка (18+ и т. п.) — если она есть у события.
- Американские приёмы инфобиза («секрет, который скрывают», «вы не поверите»,
  капслок) по-русски звучат как лохотрон — не использовать.
- Обращение (вы/ты, с прописной или строчной) — из файла контекста; не
  указано — спроси.

Выход ступени: текст по секциям страницы + список всех фактических
утверждений со ссылкой на строку файла контекста.

## 2. Ступень humanizer-ru — снимает нейросетевую манеру

Режим «редактура», регистр «маркетинг». Границы:

- Только локальная правка: TRIM, REPLACE, JOIN, SPLIT. Структуру страницы,
  порядок секций, утверждения и CTA не трогает.
- **Тире: не снимать все подряд.** Решение владельца — типографику ставит
  ru-text последней ступенью. Здесь только «частые тире» (группа C): тире как
  связка в каждом предложении — перестроить; единичное авторское — оставить.
- Сканер: `~/.claude/venvs/humanizer/bin/python <скилл>/scripts/scan.py`.
  Не запустился — сказать одной строкой, балл не выдумывать.

## 3. Ступень ru-text — грамматика и типографика

Только грамматика, пунктуация, типографика (кавычки, неразрывные пробелы, тире).
Инфостиль-чистку не повторять — она уже сделана на ступени 2, второй проход
выглаживает продающий напор.

## 4. Сверка и сдача

- Сравни список утверждений после ступени 3 со списком после ступени 1:
  ни одно не пропало, не изменилось по смыслу, не появилось новое.
- Владельцу: итоговый текст + по строке на ступень «что изменила» + балл
  сканера «было → стало», если сканер работал.
- **В файлы сайта текст идёт только после одобрения владельцем.** Дальше —
  правила репозитория сайта (в propevay: строки в шаблонах — через
  `typography()`, проверка `npm run check:typo`).
- Новый текст — это гипотеза: если на сайте есть Метрика с целями, назови цель,
  по которой судить (покупка билета, заявка), и сравнивай период до и после.
