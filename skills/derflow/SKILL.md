# derflow — роутер (v5.0)

Одна входная дверь для задачи разработки: полоса → исполнитель → модель →
сколько процесса. Человек описывает проблему обычными словами и не обязан знать,
кого звать. Здесь только маршрутизация; правила полосы — в её движке.

**Принцип v5.** Opus 5.5 сам держит длинную многошаговую работу. Процесс здесь —
только то, что закодировано реально оплаченными провалами. Всё остальное модель
решает сама; не добавляй церемоний сверх написанного.

## Анонс — до любой работы

> **🧭 Lane `<id>` → `<исполнитель>` (`<модель>`) — потому что `<причина>`.**
> Готово = `<проверяемое условие>`.

Конец прогона — строки с тем же постоянным значком на тип, в этом порядке:
`✋ Ждёт тебя: <решение/одобрение/команда>` · `⚠️ НЕ проверено — <что>, <риск>` ·
`✅ Сделано: <что, где проверено>`. Нечего сказать — строки нет; команда
человеку — блоком кода под `✋`. Значок = тип строки; не менять, не
украшать им прозу (так же 🔎 🧩 📝 у разведки ниже).

Затем движок полосы, если он у неё есть (таблица ниже), — до первой правки.
Составная задача → строка на часть. Простой вопрос («что делает X?») — не
работа: ответь без полосы и анонса.

## Репозиторий на docflow

Есть `backlog/config.yml` → всё, кроме A и простых вопросов, идёт через скилл
**`docflow`**: там задачи, замки, доки и отложка. Openspec и `waiting.py` в
таком репо не используются. Модели и исполнители — по таблице ниже.

## Триаж «сломалось» — до выбора полосы

Жалоба на поведение сама по себе не полоса. Три вопроса, не больше одного чтения
файла; не уложился — это уже Dx:

1. Выражает ли домен то, чего не хватает? **Нет → пробел модели → C.**
2. Механизм работает, но не доехал до поверхности? **→ B.**
3. Механизм ломается: встало сейчас → **F** (`_ship.md`); есть время на причину →
   **Dx** (`_lane-c.md`, затем `superpowers:systematic-debugging`). Фикс
   маршрутизируется как A/B/C.

## Полосы и модели

| Просит на самом деле | Полоса | Кто делает | Движок |
|---|---|---|---|
| переименовать, текст, значение конфига, опечатка, off-by-one | **A** | сам, сразу + тест | — |
| малое изменение, ЧТО менять ясно | **B** | исполнитель на **Sonnet** по ТЗ; ты проверяешь дифф | мини-гейт ниже |
| см. границу B/C | **C** | ты оркеструешь, задачи плана — исполнителям на **Sonnet**, критики на модели сессии | `_lane-c.md` + `_gates.md` |
| причина бага | **Dx** | **сам**, без делегирования: контекст поиска и есть работа | `_lane-c.md` |
| прод встал | **F** | сам | `_ship.md` + `_gates.md` |
| деплой · миграция · рестарт · рассылка · ротация ключа | **Ops** | сам | `_ship.md` |

**ТЗ исполнителю** — одно сообщение: что сделать, файлы/сшивка, условие «готово»,
когда остановиться и вернуть вопрос. Отчёт исполнителя — вердикт и дифф, не
пересказ: он живёт в твоём контексте до конца сессии.

**Когда делегирование не окупается:** правка связана через много файлов и
понимание уже у тебя в контексте, или исполнитель будет перечитывать то, что ты
только что прочитал. Тогда делай сам — ТЗ дороже правки.

### Мини-гейт B (вместо полного `_gates.md`)

- Прогон на самом высокофидельном доступном контуре; назови, на каком.
  Передать проверку человеку — не проверка. Непроверенное отгружай как
  «⚠️ НЕ проверено — `<что>`, `<риск>`».
- UI → смотри на рендер, не на «компилируется».
- Каждое новое публичное имя — `grep` на подключение (`| grep -v def`).
- **Полный `_gates.md` всё же грузится, если B трогает внешний API/SDK/устройство
  (контракт до парсера) или размещает новый элемент в существующей поверхности.**

## Граница B/C

| Ситуация | Действие |
|---|---|
| Баг в коде, спека описывает поведение верно | правь код, change не открывать |
| Баг там, где спеки на область нет | правь код + `descriptive` спека после |
| Баг вскрыл, что спека неверна | change; proposal объясняет, почему |
| Новая фича или изменение поведения | всегда change |
| Схема, API, публичный контракт | change + миграция и back-compat в `design.md` |

Любой один из триггеров C достаточен: двусмысленно · деньги/авторизация/биллинг/
перс-данные/публичный контракт/миграция схемы · дольше полудня · многосессионное.
Однострочная правка биллинга идёт полный цикл. Без изменения поведения —
`skip_specs: true` в `.openspec.yaml`, требование ради валидации не выдумывать.

## Вторая полоса в сессии — новой сессией

Кроме `A` и `D`, полоса, родившаяся из работы (находка Dx, фикс после
консультации, вердикт спайка), открывается **новой сессией**: хендофф →
`~/.claude/scripts/hand.sh <каталог> [файл]`, зовёшь сам. Замер: вторая полоса
`A`/`D` здесь — $26–34 на сессию; `B`–`F` здесь — $106–679 и сотни ходов.
«Корень уже в контексте» — довод ЗА расщепление: объяснимое влезает в хендофф,
остальное — мусор поиска, оплачиваемый каждым ходом. Канон — `_capture.md`.

## Исполнители и специалисты

| Ситуация | Бери | Модель |
|---|---|---|
| строить/менять структуру UI | `frontend-developer` | Sonnet |
| реализовать Python по ясной форме | `python-pro` | Sonnet |
| форма системы, границы, «файл слишком большой» | `system-architect` | сессии |
| чего НЕ хватает | `gap-finder` | сессии |
| правильный ли флоу / доступность | `ui-ux-designer` | сессии |
| UI «ощущается дёшево» | `make-interfaces-feel-better` | скилл |
| незнакомый репо | `explore-code` | скилл |
| просвет своего репо целиком | `audit-code` (дорого, потолок!) | скилл |
| баги на диффе · чистка · безопасность | `/code-review` · `simplify` · `/security-review` | — |
| сверить с артефактами заявки | `/opsx:verify` | — |
| русский текст | `ru-text` | скилл |
| разведка: сходить и посмотреть | файлы названы — сам; нет — `Explore` | Sonnet (`model: sonnet`) |

**Разведка — всегда доки → код → доки**, в любой полосе и посреди неё,
и тем же рецептом в ТЗ разведчику. На экране три строки, по одной с вызовом:
`🔎 Доки: <поиск> → нашёл <что> / не нашёл` ·
`🧩 Код: <файлы> — <чего в доках не было>` ·
`📝 В доки: <что записываю, куда>` (пробела нет — `📝 Доки верны`).
Пробел закрывается черновиком доки в этом же заходе, не строкой-предложением.
`general-purpose` на разведку не зовётся: он пишет и едет на модели сессии.

Дизайн против сборки: одно поле или прямой эндпоинт — сборка, исполнитель; к
архитектору — только когда модель данных или контракт требуют решения. Деньги
(СБП, ККТ, `KkmServer`) и российское право без своего агента: внешне-контрактный
гейт из `_gates.md`, для права — сам закон. Подходят двое — бери более узкого.

## Редкие полосы (ничего не отгружают; принятая находка перезаходит как A/B/C)

| Интент | Полоса | Маршрут |
|---|---|---|
| новый проект | **C-bootstrap** | `docflow/setup.md`, «С нуля» → брейншторм → дальше `docflow`; openspec не заводится |
| нет спеки, надо менять сшивку X | **C-adopt** | дельта только на то, что меняешь |
| заявок накопилось | **C-drain** | `/opsx:bulk-archive`, триаж до фанаута |
| «файл не слишком большой?» | **D** | `system-architect` или `simplify` → вердикт |
| «проаудируй всё» | **E** | `/code-review ultra` или многомерный ревью |
| «а можно ли вообще X?» | **Spike** | без гейта и коммита → вердикт |
| онбординг в чужой репо | **Orient** | `explore-code` по одному пути |

Docs — не полоса: точечные доки → B без специалиста; «синхронизировать доки» →
C-drain; «описать систему целиком» — сперва спроси зачем.

## Веер сабагентов — потолок до запуска

Потолок называется в воркерах и деньгах, не в токенах: **`<N>` × $5 ≈ `$<итог>`**
(замер 918 воркеров: среднее $5, девятый дециль $10; тяжёлое задание — по $10).
«Аудит» ради фичи — это scoped `explore-code`, а не whole-repo веер (боевое:
55 воркеров ≈ $275). Отчёт каждого воркера проверяется по его доказательствам
до принятия.

## Когда грузить `_capture.md`

Не в конце каждой полосы, а только если: расщепляешь сессию; задача заняла
несколько попыток или вскрыла незнакомый факт (захват урока / `self-learning`);
пишешь или чистишь память. Иначе — не грузить.

`_parallel.md` — если проектный `CLAUDE.md` объявляет параллельную работу:
ворктри до первой правки. Правка самого derflow — `_editing.md`.

## Ошибки роутинга

- Анонс без условия «готово» — модели нечем закончить.
- Делегировать Dx или правку, понимание которой уже в твоём контексте.
- Грузить движки «на всякий случай»: каждый файл платится каждым ходом сессии.
- `audit-code` как разогрев под фичу.
- Гонять агентов И руками по одним и тем же файлам.

История версий — `archive/CHANGELOG.md` (не грузить).
