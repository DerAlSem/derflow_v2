# modern-web-guidance — обёртка derflow

Обёртка над npm-пакетом `modern-web-guidance` (Google Chrome, Apache-2.0).
Пакет не вендорится (16,5 МБ, публичный `derflow_v2`): он тянется из npm и
кэшируется. Версия закреплена, телеметрия выключена.

**Каждая команда — ровно с этим префиксом** (не `@latest`, не без `DISABLE_TELEMETRY`):
пакет шлёт текст `search`-запроса в Google Clearcut, а имена наших проектов не должны
туда попадать.

```sh
DISABLE_TELEMETRY=1 npx -y modern-web-guidance@1.0.0 search "<запрос>"
DISABLE_TELEMETRY=1 npx -y modern-web-guidance@1.0.0 retrieve "<id>[,<id>]"
```

Нет сети — добавь `--offline` после `npx`. Обновление версии — осознанная правка этого
файла и `core/agents/frontend-developer.md` вместе, с чтением changelog.

## Поток (для веб-UI, CSS, клиентского JS)

1. **search** — 2–5 слов, одна платформенная возможность («light dismiss dialog»,
   «responsive data table»). Без имён фреймворков и проектных слов; составную задачу
   режь на несколько запросов. Намерение без названия примитива переведи в примитив
   («подтверждение удаления» → «confirmation modal dialog»).
2. **retrieve** по `id` совпавших гайдов плюс общий гайд дисциплины (`html`, `css`,
   `forms`, `accessibility`, `performance`, `security`), если подходит. Пусто или мимо —
   перефразируй один раз, потом иди дальше без гайда. Вывод свыше ~9,5 КБ уходит во
   временный файл — читай его целиком.
3. **Сверь код с гайдом**: современный паттерн и фолбэки из гайда применены, запрошенного
   сверх просьбы не добавлено. Фичи не из Baseline widely available — только с фолбэком
   гайда, если проект не объявил свою политику поддержки браузеров.
4. **Раскрой использование**: в конце ответа секция `### Modern Web Guidance` — по
   строке на применённый `id` (что неочевидное он потребовал и от какой ловушки уберёг)
   или одна строка «проверил такие-то темы, не применимо». Без этой секции пилот
   нельзя оценить.

Гайды на ванильном HTML/CSS/JS: во фреймворке адаптируй, не выбрасывая фичу (новые
атрибуты — через каст/spread, SSR — с защитой `window`, per-instance id).

## Аудит устаревших паттернов — только по прямой просьбе

```sh
DISABLE_TELEMETRY=1 npx -y modern-web-guidance@1.0.0 legacy-scan <путь> --json
```

Не запускай при правке конкретной фичи. Это подмножество каталога (~20%).
Каждую находку проверь по `keepWhen`/`dropWhen`: фолбэки, вендорный код и
двойники — ложные срабатывания. Отчёт — проверенные находки; править код — только
если попросили модернизировать, затем перескан изменённых файлов. Не подгоняй код
под нулевой скан.

## Политика браузеров

Если проект её не объявил, а целевая среда ограничена (Electron, Telegram WebView,
конкретные браузеры), предложи записать строку `**Browser Support:** …` в его `CLAUDE.md`.
