## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Оба предела найдены 25.11.2026 в прогоне DF-25 на копиях стенда после её правки и записаны там пределами — в doc-6 и в датированном блоке шапки стенда. Задача заведена по решению владельца 26.11.2026 («задачу заводи»). Класс тот же, что у DF-25: сканер своего текста в статической половине укуса «испытываемый файл» расходится с bash — вызов мимо "$W" остаётся не назван при зелёном счёте, ложное зелёное тихое. Сдвиг в арифметике: `X=$((1<<rc))` — «<<» вне кавычек, и сканер принимает его за открыватель heredoc с тегом `rc`. Копия, где дальше идут вызов мимо на ~/.claude/scripts/waiting.py и строка `rc`, даёт ✅ 226 ❌ 0; без строки `rc` — ✅ 225 ❌ 1 с причиной «тело heredoc не закрыто: rc», вызов не назван. Терминатор `<<-` с табом перед тегом: `cat <<-TAB >/dev/null`, тело, строка из таба и `TAB` — для bash законный терминатор, а сканер его не узнаёт и тянет тело до строки с одним тегом. Вызов мимо после настоящего терминатора не читается, копия даёт ✅ 226 ❌ 0. Тот же heredoc с терминатором без таба ловится: ✅ 225 ❌ 1, одна причина. Третий сосед — тег в подстановке `<<"$переменная"`, лишнее красное громкое — в задачу не входит: решения по нему не было.

Подстановка и бэктики внутри арифметики исполняются: X=$(( $(python3 зонд) + 1 )) и с бэктиками — метка есть; X=$( (python3 зонд) ) с пробелом — метка есть. (2) let x=1<<rc, declare -i x=1<<rc, x=1<<rc, echo 1<<rc — для bash НАСТОЯЩИЕ heredoc, сканер с bash согласен, это не предел. (3) Ложный открыватель остаётся у арифметической команды (( x=1<<rc )) — в задачу не входил, записан пределом числом (копии m20, m20b).
