## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Предел найден 26.11.2026 в DF-28 короткими текстами, записан 27.11.2026 пределом в doc-6 и шапку стенда, без задачи; заведена по решению владельца 28.11.2026 — только завести, исполнять не приказано. Конструкция `X="`cat <<EOF … EOF`"` — heredoc в бэктиках под двойными кавычками, без скобок подстановки: для bash 3.2.57 настоящий heredoc (зонд `dev/bash28b.py`, случай C15), а сканер открыватель не узнаёт и читает тело как код — ложное красное громкое. Тот же heredoc внутри скобок под двойными кавычками узнаётся с DF-28 (`dev/awk28.py`, случай H22).

Почему после DF-31. Копия m25 (`mkmut2.py`, «m25-heredoc-в-бэктиках-под-двойными»): в теле heredoc стоит вид вызова мимо, за конструкцией — строка вызова стенда. Копия даёт ✅ 225 ❌ 1, но не своим укусом: с кириллицей в теле awk падает раньше, чем называет вызов, — «статическая половина не прочитала текст: awk вышел кодом 2». После DF-31 (авария awk) копия ожидается ✅ 225 ❌ 1 с «запуск мимо переменной пути» — это укус, который снимает задача.

Материал. Doc-6 — пункт предела «Heredoc в бэктиках под двойными кавычками без скобок» в списке «остались пределами» и абзац «Незакрытое тело heredoc и отказ `awk` краснят…»; комментарий над программой (строки 465–469 на `ad2e1fc`); заметки DF-28 — `backlog task view DF-28 --plain`, раздел «Ждёт тебя». Оснастка вне git — `~/dev/derflow/stands/wb-mutants`: зонд bash 3.2.57 — `dev/bash28.py` (62 случая) и `dev/bash28b.py` (21 случай); короткие тексты `python3 dev/awk28.py <стенд> after` (86 случаев); `bash run2.sh <метка> live,mut,mut2 <путь к waiting-bite.sh>` (сводка в `out/<метка>.txt`). База на `ad2e1fc`, сводка `out/root28.txt`: живой ✅ 226 ❌ 0 из ztui и из чистой среды, m25 ✅ 225 ❌ 1.
