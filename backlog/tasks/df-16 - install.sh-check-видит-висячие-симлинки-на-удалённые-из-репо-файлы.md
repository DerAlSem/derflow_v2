## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
23.11.2026 трижды за день в живом каталоге оставался симлинк на файл, удалённый из репо: распущенный агент `vision` (DF-14), `core/hooks/glm-blind.py` и `core/scripts/see.sh` (DF-15.2), `hosts/opencode/plugins/vision-probe.js` (DF-15.3). Каждый снимали руками, потому что `./install.sh --check` отвечал «дрейфа нет»: функция `link` обходит только цели, которые сейчас есть в репо, и до симлинков на исчезнувшие файлы не доходит. Висячий симлинк опасен молчанием: он оживает, если файл с тем именем вернётся в репо, а по «дрейфа нет» уборка считается сделанной. Отдельно файл-симлинк в корне `~/.zcode/skills` валит дискавери всего корня (память `zcode-discovery-symlinks`).

Контекст, которого в коде нет:

- В живых каталогах есть висячие симлинки не от install.sh: на 23.11.2026 девять в `~/.zcode/skills` вели в исчезнувший `~/.claude/skills/synced/fe0c6cc2-…`, ещё `~/.claude/debug/latest`. Вечный «дрейф» из-за чужих ссылок хуже слепоты — свои надо отличать от чужих.
- Живые каталоги: `~/.claude`, `~/.zcode`, `~/.config/opencode`. kimi-work ставится копиями, не симлинками; `~/.claude/settings.json` не линкуется и правится руками.
- Стенд: `./install.sh --claude-dir <стенд> --only claude` из ворктри (`derflow/_editing.md`). Сторож проверяется укусом, образец — `core/scripts/waiting-bite.sh`.
