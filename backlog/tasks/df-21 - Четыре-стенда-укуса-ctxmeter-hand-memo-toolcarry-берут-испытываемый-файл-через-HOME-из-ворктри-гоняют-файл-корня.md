## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Найдено 24.11.2026 в DF-20 (сессия C·20, итог «Ждёт тебя»). Решение владельца 24.11.2026: завести задачу, все четыре стенда сразу, новой сессией (хендофф C·21, `.claude/handoff/bites-own-file.md`). Образец — DF-20 (`0703235`, doc-6), где тем же способом починен пятый стенд, `waiting-bite.sh`.

**Дефект.** `~/.claude/scripts` и `~/.claude/hooks` — симлинки на живой корень `core/scripts` и `core/hooks`. Стенд, берущий испытываемый файл через `$HOME/.claude/…`, из ворктри молча гоняет файл КОРНЯ: прогон зелёный на любой правке ворктри и молчит о ней. Так делают четыре (строки на `6369d63`): `ctxmeter-bite.sh:17`, `hand-bite.sh:18`, `memo-bite.sh:39`, `toolcarry-bite.sh:25`. Остальные три берут файл рядом с собой — не трогать: `install-bite.sh`, `handoff-bite.sh`, `waiting-bite.sh`.

**Измерено на `6369d63` до правки.** Испытуемый файл в ворктри сломан, путь не подменён:

- ctxmeter — файл ворктри подменён молчащей заглушкой: из ворктри ✅ 7 ❌ 0, корень в тот же момент ✅ 7 ❌ 0;
- toolcarry — та же подмена: ✅ 14 ❌ 0 и ✅ 14 ❌ 0;
- memo — та же подмена: ✅ 64 ❌ 0 и ✅ 64 ❌ 0 (в шапке стенда счёт от 08.09.2026 — 53, живьём 64);
- hand — в `hand.sh` ворктри снят гейт «подобранный хендофф обязан объявлять ветку» (`exit 5` → `exit 0`, строка 195): ✅ 20 ❌ 0 и ✅ 20 ❌ 0.

Заглушка через подмену (молчит, exit 0): ctxmeter ✅ 0 ❌ 7, toolcarry ✅ 0 ❌ 14, memo ✅ 0 ❌ 64, hand ✅ 2 ❌ 18. У hand зелёны два старых укуса с обратной иголкой («предупреждения быть НЕ должно»): отрицание без положительной половины, молчащая заглушка проходит его даром. Критерий «заглушка даёт ✅ 0» на hand достижим только их спайкой.

**Среда.** Шелл сессии ztui несёт `ZCODE_SESSION_ID`, `ZCODE_PROJECT_DIR`, `CLAUDE_CODE_SESSION_ID`, `CLAUDE_PROJECT_DIR`, `CLAUDE_SESSION_ID`. Разницы в счёте между голым прогоном из него и чистой средой нет ни у одного из четырёх (ctxmeter 7/0 и 7/0, hand 20/0 и 20/0, memo 64/0 и 64/0, toolcarry 14/0 и 14/0). Но `ctxmeter-bite.sh:28` гоняет `python3 "$M" --tool` с наследованной средой, а `context-meter.py` по `ZCODE_SESSION_ID` переходит на контракт ZCode (`:155–175`, `:290–291`): `emit()` печатает JSON вместо plain, пороги `WARN_Z`/`LOUD_Z`, текст зовёт `~/.zcode/scripts/hand.sh`. Иголки «hand.sh» и «420k» переживают JSON-строку, поэтому стенд зелёный — на чужом контракте, и какой контракт проверен, зависит от того, из какого шелла его позвали.

Остальные три испытуемых среду сессии почти не читают: `memo.py:215` берёт `CLAUDE_CODE_SESSION_ID` — только метка сессии вердикта, стенд задаёт её явно там, где она иголка; `hand.sh` на сухом пути (`-n`) переменных сессии не читает; `toolcarry.py` среду не читает вовсе.

**Не трогать:** испытуемые `context-meter.py`, `hand.sh`, `memo.py`, `toolcarry.py` — если честность потребует правки в них, остановиться и спросить владельца. Прежние датированные блоки замеров в шапках не пересчитывать.

Правка — только четыре стенда.

## Implementation Plan

1. Дока capability на четыре стенда по факту кода ДО правки — отдельный коммит, чтобы было с чем сравнить.
2. В каждом стенде: `HERE` физическим путём (`cd -P`), файл по умолчанию — из своего чекаута (`$HERE/<файл>`; у ctxmeter файл лежит в `core/hooks`, то есть `$HERE/../hooks/`); первая строка прогона — `испытываемый файл: <путь> — <почему он>`; usage в шапке.
3. `ctxmeter-bite.sh`: обёртка `meter()` с `env -u ZCODE_SESSION_ID`, через неё `run()` и прямой вызов мимо него.
4. Новые укусы, каждый спаян с положительной половиной: в четырёх стендах — «файл своего чекаута (или назван подменой), и он же сделал основное»; в ctxmeter — «ZCODE_SESSION_ID подложен, вывод остаётся plain». В `hand-bite.sh` — положительная половина у двух старых укусов с обратной иголкой: заглушка обязана давать ✅ 0.
5. Проверка из ворктри и из корня: голый прогон из шелла ztui и в чистой среде — счёт равный; заглушка → ✅ 0; сломанный файл в ворктри без подмены краснит из ворктри, из корня зелёный; подмена сломанной копией — то же множество красных, что у стенда до правки с той же копией; `bash -n`.
6. Мутации стенда (копии в /tmp, дерево не трогать): возвращён старый путь через `$HOME` — краснеет укус про свой файл; в ctxmeter снята нейтрализация — краснеет укус про `ZCODE_SESSION_ID`. Числа — новым датированным блоком в шапке, прежние блоки не пересчитывать.
7. Ревью — критик `gap-finder`, свежий контекст. Дока — к состоянию после правки.
8. Финализация: `backlog instructions task-finalization`, `--check-ac` по каждому, `--final-summary` (Ждёт тебя · Сделано · Найдено), `bl-done.sh`.
9. Влитие как в DF-19/DF-20: в корне ff-only под замком, пуш, закрывающий коммит вторым ff, `./install.sh --check`. Жатва ворктри (cwd — корень). Память: вытеснить `bite-stands-root-file-from-worktree`.
