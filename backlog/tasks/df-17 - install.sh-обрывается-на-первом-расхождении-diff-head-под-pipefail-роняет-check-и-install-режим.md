## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
24.11.2026, найдено при закрытии DF-16. В `install.sh` две сверки печатают расхождение через `diff … | head -20`: отставший `hosts/*/generated` (п. 1) и хуки в `settings.json` Claude Code (п. 2). Обе строки стоят в теле `if`, а не в его условии, и под `set -euo pipefail` любой непустой diff выходит не нулём: замер даёт 1, при выводе длиннее 20 строк возможен 141 от SIGPIPE. Сценарий падает на печати diff, и всё, что ниже по ходу, не выполняется.

Последствие для `--check`: не проверяются живые пути, копии kimi-work и висячие симлинки (п. 3–7). Сторож DF-16 при любом дрейфе сборки или хуков слепнет: код 1 есть, а висячий симлинк не назван. Для install-режима: после Claude Code не раскладываются zcode, opencode и kimi-code.

Контекст, которого в коде нет:

- Замер 24.11.2026 на поддельном HOME с разошедшимися hooks (пишущая сессия DF-16). `--check`: код 1, не названы ни висячий симлинк, ни пропавшая управляемая ссылка zcode, ни «дрейф найден» — до разделов 3–7 не дошёл. Install-режим: разложено 23 ссылки, все в `~/.claude`; до zcode, opencode и kimi-code не дошло.
- Сверку сборки end-to-end не мерили. Тот же приём подтверждён минимальным воспроизведением: `set -euo pipefail; diff <(printf 'a\nb\n') <(printf 'a\nc\n') | head -20; echo reached` печатает diff и выходит с кодом 1, до `echo` не доходит.
- На живой машине 24.11.2026 сборка и hooks в согласии, поэтому обрыв не виден. Он проявится первым же расхождением хуков: живой `settings.json` не линкуется, хуки в нём правятся руками после правки канона.
- Оснастка: укус `core/scripts/install-bite.sh` (16 укусов на поддельном HOME); его install-режим пересобирает `hosts/*/generated` в репозитории, укус сверяет дерево до и после. Дока: doc-4, абзац «Предел на 24.11.2026».
