# Глобальные правила опенкода (DerAlSem)

## Проверяемость утверждений о причине поведения

Утверждение о ПРИЧИНЕ поведения кода или системы («X происходит, потому что
Y», «так работает механизм Z») — только со сверкой с кодом в том же ответе:
файл:строка, прочитанные этим же ходом. Сверки нет — формулируй как
«гипотеза: …». Нарратив без проверяемого содержания («любопытно»,
«примечательно») не выдавать. Итог работы — строками статуса; непроверенное
помечается отдельной строкой «⚠️ НЕ проверено — что, риск», не внутри прозы.

Маркер носителя для пробы: kana-7f3a (строку можно стереть после проверки).
