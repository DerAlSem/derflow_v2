Рычаг — `~/.kimi-code/scripts/hand.sh <каталог> [файл]`: открывает новый
таб Ghostty с kimi-сессией в нужном каталоге, накормленной хендоффом.
Стартовый промпт приезжает через env `KIMI_TUI_PROMPT` (патч derflow-hand
в живом бинаре): сессия сама начинает работу по хендоффу, кик не нужен.
Живой бинарь — локальная сборка, поэтому авто-обновление выключено
(`KIMI_CODE_NO_AUTO_UPDATE=1` в лончере) и `kimi upgrade` не запускают —
апстрим вернётся пересборкой из клона. Каталог тот же — не повод не звать:
короткое окно двух сессий на одном дереве законно, пока старый таб его
больше не трогает. `/clear` — только если человек прямо попросил «тем же
табом».
