Рычаг — `~/.kimi-code/scripts/hand.sh <каталог> [файл]`: открывает новый
таб Ghostty с kimi-сессией в нужном каталоге, накормленной хендоффом.
Сеялка `kimi -p` читает хендофф и подтверждает состояние, интерактив
продолжает ту же сессию через `kimi -c`. Напечатать команду человеку на
копипасту — нарушение канона, а не вежливость. Каталог тот же — не повод
не звать: короткое окно двух сессий на одном дереве законно, пока старый
таб его больше не трогает. `/clear` — только если человек прямо попросил
«тем же табом».
