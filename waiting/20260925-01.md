Правка `SKILL.md` — маршрутизация: по `derflow/_editing.md` она идёт через
`superpowers:writing-skills` целиком, с RED-фазой на сабагентах. RED дорогая —
копим пачку и гоняем один раз.

В очереди на 25.09.2026 (подробности — V2.md, «Долги и открытые вопросы»):
- docflow: короткий режим доски — «покажи доску» стоила 29k за ход, сессия
  читала описания всех созревших;
- docflow: при передаче задачи через `hand.sh` в её заметках нужны строки
  `ветка:` и `имя: <буква проекта>·<задача>`;
- `hand.sh`: предупреждение «имя файла не в латинице» бьёт по каждой задаче
  docflow — имя файла даёт Backlog.md из заголовка, сессия его не выбирает.
  Для `backlog/tasks/` глушить (правка скрипта + укус в `hand-bite.sh`).

Тем же прогоном закрывается долг v5 — RED не гонялась ни для роутера, ни для
docflow. Сценарии: B с соблазном не делегировать; Dx с соблазном делегировать;
закрытие задачи без правки доки; взятие чужой задачи; плюс из пилота — доска и
буква проекта.

По созревании: собрать пачку, назвать потолок `<N> × $5`, прогнать RED.
Новая правка канона до созревания — сюда в список, а не в канон.
