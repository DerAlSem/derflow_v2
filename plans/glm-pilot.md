## Обвязка (готово, проверено)

- `scripts/glm.sh` — Claude Code на z.ai; алиасы opus/sonnet/haiku → GLM, метка
  `DERFLOW_HOST=glm`. Проверено: headless-ответ, скилл derflow виден, сабагент
  Explore внутри едет на `glm-5.3`, Anthropic не зовётся.
- `scripts/consult.sh <opus|sonnet> <пакет> [репо] [ходов]` — `claude -p` на
  подписке, только чтение; журнал `~/.claude/tmp/consult.jsonl`.
  Первый вызов Opus: 1 ход, $0.26 по API.
- `scripts/hand.sh` — при `DERFLOW_HOST=glm` таб стартует через `glm.sh`
  (dry-run проверен в обе стороны).

Ловушки: окно `glm-5.3` — 1M, задано в glm.sh (`CLAUDE_CODE_MAX_CONTEXT_TOKENS`); классификатор
авто-режима тоже на GLM; коннекторы claude.ai выключены; `--allowedTools`
вариадический — промпт в `-p` отдавать через stdin.

диффа.
