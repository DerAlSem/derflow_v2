# derflow · правка самого derflow

Читается, только когда рабочий каталог — сам `~/.claude` и правится канон
(`SKILL.md`, движки `_*.md`, агенты, хуки).

## Правка разводится по типу — решение владельца 01.09.2026

| Что правишь | Как |
|---|---|
| **Маршрутизацию**: новая полоса, изменённая классификация, новое обязательное правило, любая правка `SKILL.md` | `superpowers:writing-skills` целиком, RED-фаза на сабагентах обязательна |
| **Довесок в движок**: замер, ловушка, факт, строка в «Ошибки этой главы» | гейт промоушена `_capture.md`: пройденная проверка + названный отказ + один исключённый тупик. Сабагенты не нужны |

Спорный случай считать маршрутизацией. Признак довеска — он описывает цену,
которую уже заплатили, и не меняет ни одного решения роутера.

**Стенд RED/GREEN для роутера — не сабагент.** Промпт сабагента не несёт
роутера: 25.09 он давал 3/3 провала и ДО, и ПОСЛЕ правки. Стенд — `claude -p`
в целевом репо; RED — с `CLAUDE_CONFIG_DIR` на `git worktree` `~/.claude` до
правки (разовый `/login` владельца в его терминале). Воспроизводи провал в
состоянии, где он случился: RED на свежем стенде не воспроизвёлся — причиной
был отставший корень репо, а не канон (`a5917d5`).

## v5: вес канона — часть правки

Каждая строка роутера платится каждым ходом каждой сессии разработки. Новое
правило в `SKILL.md` входит только вместе с ответом «что из существующего оно
заменяет или почему не может жить в движке». Движки держат бюджет строк
(`scripts/canon-budget.py`).

## Правка файла — read-modify-write, а не мерж

`~/.claude` общий на все сессии сразу, конфликта git не будет: перезапишешь
чужую главу молча. Правило — `_parallel.md`, глава «Изоляция ворктри достаёт
не везде»; замер — `archive/isolation-surfaces.md`.
