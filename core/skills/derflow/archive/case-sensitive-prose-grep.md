# Регистрозависимый греп по прозе врёт пустотой (архив derflow, глава _gates, 16.09.2026)

Родственник главы «Пустой вывод поиска — не находка, пока не проверен код
возврата», но отказ другой и лечится иначе. Там поиск **не запускался**: `rc`
был ненулевой, пустота приходила из отказа. Здесь поиск отработал штатно,
`rc=0`, вывод честно пуст — **неверен был запрос**.

📏 Боевое, mprz.ru 16.09.2026, ложный бейдж «⚠ Реконструкция» на счёте, у
которого снимок есть. Хендофф под задачу объявлял полосу B с обоснованием:

> Не C: спеки на эту область нет вовсе (`grep` по `openspec/specs` не находит
> ни «Реконструкц», ни `has_snapshot`).

```
grep -rn  "Реконструкц" openspec/specs/   # пусто, rc=0
grep -rin "реконструкц" openspec/specs/   # invoice-doc-snapshot/spec.md:52
```

Спека на область существовала и прямо предписывала ту самую пометку:
«SHALL пометить в UI, что это реконструкция, а не отправленный оригинал».
Искали слово в том виде, в каком оно стоит **на экране** — с заглавной, как в
подписи бейджа. В прозе оно стоит строчным: русский текст поднимает регистр
только в начале предложения и в именах собственных, и форма из интерфейса
почти никогда не совпадает с формой из текста.

Цена не «лишний греп». Вывод «спеки нет» переводит задачу на другую строку
таблицы границы B/C — с «баг там, где спеки на область нет» на «спека
описывает поведение верно», — и адресует descriptive-спеку не той capability:
хендофф называл `invoice-reissue` (там бейдж родился коммитом), тогда как дом
требования — `invoice-doc-snapshot`. Дубль требования в двух спеках расходится
молча, и это ровно тот долг, который спека заводится предотвращать.

Названный отказ: **на идентификаторы правило не распространяется.** У
`has_snapshot` регистр значащий, и его отсутствие в спеках было настоящим
фактом — искать символ кода регистронезависимо значит ловить шум.

Тупик, который стоит исключить сразу: **«грепать всё через `-i`» — не лечение.**
В коде регистр различает символы, и сплошной `-i` заливает вывод совпадениями,
среди которых находка тонет. Граница проходит не по инструменту, а по предмету
поиска: проза против идентификатора.

📏 Правило: **слово ищется по основе и без регистра, символ — точно.** «Нигде
не упоминается» про понятие, а не про идентификатор, добыто регистрозависимым
грепом по целому слову — это «не искал».
